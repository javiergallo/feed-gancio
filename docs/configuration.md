# Configuration

Here you can find all available configuration options using ENV variables.

## Config

| Name                                       | Type               | Default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Description                                                          |
|--------------------------------------------|--------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------|
| `CLASSIFIER_MODEL`                         | `string`           | `"joeddav/xlm-roberta-large-xnli"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Hugging Face model ID used to classify feed entries.                 |
| `LLAMA_MODEL_PATH`                         | `Path`             | `"./llama-3.2-1b-instruct-q8_0.gguf"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Path to the local GGUF language model file.                          |
| `PROMPT_CONTEXT_MAX_LENGTH`                | `integer`          | `1024`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Llama context-window size and maximum system-prompt length.          |
| `TEMPERATURE`                              | `number`           | `0.0`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Sampling temperature for the Llama model; used for datetime parsing. |
| `IMAGE_SELECTOR`                           | `string`           | `"img"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | CSS selector used to find an event image in feed HTML.               |
| `LOCALE`                                   | `string` \| `null` | `null`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Optional locale for localized dates and times.                       |
| `HYPOTHESIS_TEMPLATE`                      | `string`           | `"This example is {}."`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Template used to score candidate labels for feed text.               |
| `ASSUME_SCHEDULABLE_EVENT`                 | `boolean`          | `false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Skip classification and treat every feed entry as an event.          |
| `SCHEDULABLE_EVENT_MIN_SCORE`              | `number`           | `0.4`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Minimum classifier score required to accept an event.                |
| `SCHEDULABLE_EVENT_LABEL`                  | `string`           | `"schedulable event"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Classifier label that identifies schedulable events.                 |
| `OTHER_CANDIDATE_LABELS`                   | `array`            | `["news","statement"]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Alternative labels compared with the schedulable-event label.        |
| `DATE_FORMAT`                              | `string`           | `"%A, %B %d, %Y"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | strftime format for the current date included in prompts.            |
| `TIME_FORMAT`                              | `string`           | `"%H hours and %M minutes"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | strftime format for the current time included in prompts.            |
| `START_KEY`                                | `string`           | `"start"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | JSON key used for the parsed event start datetime.                   |
| `END_KEY`                                  | `string`           | `"end"`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | JSON key used for the parsed event end datetime.                     |
| `DATETIME_STRS_EXTRACTION_PROMPT_TEMPLATE` | `string`           | `"You are a helpful assistant that extracts date-time information from text. You will be given a text that refers to a schedulable event. You must extract the event's start date-time, and ending date-time if possible (empty string if not possible). You must return the extracted information in a JSON object with the following keys: {start_key} and {end_key}. The values of the keys must be strings. The date-time strings must be in a format that can be parsed by dateparser.parse(). Today's {today_str}, it's {now_str}. "` | Prompt template for extracting event start and end datetime strings. |
| `DATETIME_EXTRACTION_PROMPT_TEMPLATE`      | `string`           | `"You are a helpful assistant that extracts date-time information from text. You will be given a text that refers to date-time information. You must extract the date-time, ISO formatted. Today's {today_str}, it's {now_str}. "`                                                                                                                                                                                                                                                                                                          | Prompt template for normalizing one datetime to ISO format.          |
